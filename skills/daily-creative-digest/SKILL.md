# Daily Creative Digest（每日创意日报）

## Overview

每天收集**全领域**的创意内容、有趣冷知识与赚钱新思路，整合成一份跨行业 Markdown 日报。

**核心定位：跨行业创意灵感库，刻意避开"科技互联网一头沉"。** 必须有农业、建筑、文旅、宠物、体育、银发、教育等非科技领域的实质内容。

## 输出文件

- 保存路径：`~/Documents/Daily news/每日创意/每日创意_YYYY-MM-DD.md`
- 文件名：`每日创意_` + 当天日期（如 `每日创意_2026-09-17.md`）
- 保存目录不存在时先创建（`mkdir -p`）

## 执行流程

### Step 1: 确认日期

用 `date +%Y-%m-%d` 获取当天日期，不要自己推算；所有搜索词带上具体日期。

### Step 2: 搜索素材

**必须覆盖以下不少于 12 个领域**，每个领域至少搜索 1-2 次：

1. 🏭 制造业 / 工业 / 新材料 — 新工艺、新设备、新材料突破
2. 🌾 农业 / 食品科技 — 智慧农业、新食材、替代蛋白、功能性食品
3. 🏛 建筑 / 建材 / 家居 — 绿色建筑、智能家居、适老改造、装修趋势
4. 🎨 文化艺术 / 展览 / 电影 / 音乐 — 新展览、新电影、新艺术形式
5. 👔 时尚 / 美妆 / 奢侈品 — 可持续时尚、新面料、新品牌
6. 🏥 医疗健康 / 银发经济 — 新疗法、健康管理、养老新模式
7. 🐾 宠物经济 — 宠物食品、宠物医疗、智能宠物用品
8. ⚽ 体育 / 健身 / 新兴运动 — 新运动项目、健身新趋势、赛事
9. 🏡 文旅 / 乡村振兴 / 民宿 — 新景点、文旅创新、非遗活化
10. 📚 教育 / 职业培训 — 教育改革、新职业、技能培训
11. 💻 科技 / 互联网 / AI — AI 新应用、硬件创新、前沿技术
12. 💰 金融 / 商业 / 零售 — 消费趋势、新商业模式、投资机会
13. 🌱 环保 / 可持续 / ESG — 绿色创新、循环经济、碳中和
14. ✂️ 手工艺 / 设计 / 创意服务 — 手工经济、设计创新、个人 IP

**数量要求（硬性）**：

| 板块 | 最低数量 | 要求 |
|------|---------|------|
| 💡 创意灵感 | 覆盖 **≥10 个不同领域** | 每条要有「为什么有意思」的深度解读 |
| 🎯 趣闻新知 | **≥10 条** | 覆盖自然、科学、生活、人文等多角度 |
| 💰 赚钱新思路 | **≥7 条** | 覆盖 ≥5 个不同行业 |
| 🔗 跨界灵感 | **≥5 个** | 跨领域组合灵感，如 农业×AI、建筑×适老 |

### Step 4: 保存

写入文件后结束任务，向用户简要汇报各板块条数与最值得一看的 3 条，**不要把全文粘贴到对话里**。

## 注意事项

- **只用真实搜索结果，禁止编造案例、数据或来源**；每条尽量标注来源出处
- 避免过度集中在科技互联网，非科技领域必须占相当比例
- 「赚钱新思路」要写清可执行路径，不要空谈概念
- 报告全文使用简体中文；国外内容翻译成中文，可保留原名
- 涉及境外地区时按中国官方表述规范书写（中国台湾/中国香港/中国澳门）
- 不收录违规、低俗、涉政内容
