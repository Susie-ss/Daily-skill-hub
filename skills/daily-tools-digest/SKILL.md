# Daily Tools Digest（全网全球工具日报）

## Overview

每天收集全球全网、**不限行业**的热门工具与新发布工具，整合成一份 Markdown 报告。

**核心定位：「工具」是全领域广义概念。** 不限于互联网/软件/数字工具，而是涵盖所有领域的实体工具。总量 15–35 条，数字工具与实体工具各占一定比例。

## 输出文件

- 保存路径：`~/Documents/Daily news/全网全球工具日报/热门工具YYYY-MM-DD.md`
- 文件名：`热门工具` + 当天日期（如 `热门工具2026-09-17.md`）
- 索引文件：`~/Documents/Daily news/全网全球工具日报/index.md`
- 保存目录不存在时先创建（`mkdir -p`）

## 执行流程

### Step 1: 确认日期

用 `date +%Y-%m-%d` 获取当天日期，不要自己推算；所有搜索词带上具体日期。

### Step 2: 搜索素材

按下面两大类逐项搜索，每类都要实际搜到内容，缺口用多轮搜索补全。

**数字 & 软件工具**

1. AI 工具及应用 — 新发布的 AI 产品、AI 应用（不限领域）
2. 开发者工具 — 新 CLI、框架、库、IDE 插件、DevOps 工具
3. 创意 & 设计工具 — 设计、视频/音频、内容创作、3D/建模工具
4. 数字效率工具 — App、浏览器插件、桌面应用、SaaS

**实体 & 物理工具**

5. 五金 & 电动工具 — 电钻、电锯、扳手、激光测距、水平仪
6. 智能硬件 & 消费电子 — 智能家居、IoT、可穿戴、阅读器、相机
7. 工业 & 专业工具 — 制造设备、焊接、3D 打印、CNC、检测仪器、实验设备
8. 医疗 & 健康工具 — 医疗器械、健康监测、健身器材、康复设备
9. 家居 & 厨房工具 — 厨具、刀具、收纳、清洁、家居维修
10. 户外 & 园艺工具 — 园艺剪、割草机、露营、野炊、骑行装备
11. 手作 & 创意工具 — 绘画、雕刻、陶艺、编织、刺绣、模型制作
12. 汽车 & 交通相关 — 汽车维修工具、车载工具、骑行装备
13. 教育 & 科学工具 — 教学用具、实验仪器、显微镜、天文望远镜

**参考搜索词**（可自由扩展）：

- 数字侧：`Product Hunt today trending`、`GitHub trending repositories today`、`new AI tools launch {date}`、`new developer tools {date}`、`Hacker News new tools show {date}`
- 实体侧：`best new power tools 2026`、`new smart home devices launch {date}`、`new kitchen tools gadgets 2026`、`new medical devices tools 2026`、`new industrial tools equipment 2026`、`new garden tools 2026`、`best new workshop tools 2026`、`new woodworking tools 2026`、`Kickstarter new tools hardware {date}`、`新上市 五金工具 {date}`、`智能硬件 新品发布 {date}`

### Step 3: 整合生成报告

**⚠️ 硬流程：先定板块配额，按配额写作，禁止「先自由写作再事后大砍」。**
历史多次教训（09-20 / 09-22 / 09-23）均因事后精简而浪费大量工具调用，且易误删章节标题。
写作前先按下表写死配额（合计 **35**），**逐板块写满即停笔**，每写完一个板块立刻确认条数：

| 板块 | 配额 |
|---|---|
| 🔥 今日精选 TOP 5 | 5 |
| 🤖 AI / 数字工具 | 5 |
| 💻 开发者工具 | 6 |
| ⚡ 效率 & 生活 App | 5 |
| 🔧 五金 & 电动工具 | 3 |
| 🏠 家居 & 厨房工具 | 4 |
| 🧰 专业 & 工业工具 | 4 |
| 🏋️ 健康 & 户外工具 | 3 |
| 🌍 其他热门工具 | 5 |

（可根据当日素材丰歉在 ±1~2 内微调，但合计必须落在 15–35，数字/实体两边都要有。）

按下面的模板生成 Markdown：

```markdown
# 🛠 热门工具 {YYYY-MM-DD}

> 🌐 全网全球 | 不限行业 | 实体与数字工具全覆盖
> 生成时间：{YYYY-MM-DD HH:mm}

## 🔥 今日精选 TOP 5

{精选 3-5 条最亮眼的工具，横跨实体和数字领域}
```

**每条工具必须包含**：工具名称、一句话中文简介、所属领域（数字 / 实体）、来源平台、链接 URL。海外产品标题保留原名，中文简介加在括号内。

优先收录今日或近 48 小时内新发布/热门的内容。

### Step 4: 更新索引

向 `index.md` 追加一行（文件不存在时先创建带标题的索引）：

```markdown
- [热门工具 {YYYY-MM-DD}](./热门工具{YYYY-MM-DD}.md) — {item_count} 条工具
```

### Step 5: 保存

写入文件后结束任务，向用户简要汇报今日收录条数与 3 条最亮眼的工具，**不要把全文粘贴到对话里**。

## 注意事项

- **写作后必做计数复核（不可跳过）**：
  1. 总条数：`grep -c "^- \*\*" 热门工具{今日}.md`
  2. 分板块：`awk '/^## /{sec=$0} /^- \*\*/{c[sec]++} END{for(s in c) print c[s]"  "s}' 热门工具{今日}.md | sort -rn`
  3. 章节完整性：`grep "^## " 热门工具{今日}.md`（多行删除后必查，防止误删板块标题）
  4. 数字/实体拆分：`grep -o "（数字工具[^）]*）"` 与 `grep -o "（实体工具[^）]*）"` 分别计数——**不要用简单 `grep -c "（实体工具"`，因为存在「（实体工具/医疗）」这类带子类后缀的写法，会导致计数虚高。**
  5. 索引行条数必须与实际实测值一致，禁止手填推测数字。
- **去重排查**：生成前用
  ```bash
  for k in <关键词列表>; do echo "== $k"; grep -l "$k" 热门工具2026-09-*.md 2>/dev/null; done
  ```
  批量比对本月历史报告，命中的再用 `grep -o ".\{0,70\}<词>.\{0,70\}"` 看上下文判断是否同一产品（同名不同产品线可收录，如 iRobot Roomba Max 875 vs Roomba Duo）。
- **品牌轮换**：同一品牌（尤其 Bosch / Makita / DeWalt / Milwaukee / Ryobi 等）避免连续两期收录；若近期已用，改用同期其他品牌的新机型，并在来源标注为横评/展会汇总。
- **同日重跑（排期变更或手动二次触发）**：若 `热门工具{今日}.md` 已存在且完整，不要整体重写丢弃已有成果，改为「增量刷新」——先搜索确认上次生成之后新增的内容，再替换掉较旧/较弱的条目，保持总数仍在 15–35，并把 `index.md` 中该行的条数与数字/实体拆分同步改对。
- **只用真实搜索结果，禁止编造工具、链接或热度数据**
- 实体工具与数字工具都要有，不要全部集中在 AI/软件
- 检查链接可用性，失效链接要剔除或替换
- 报告全文使用简体中文
- 不收录违规、低俗内容
