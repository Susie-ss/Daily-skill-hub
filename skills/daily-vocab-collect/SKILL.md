# Daily Vocab Collect（每日知识收纳 · 多看）

## Overview

每天收集全球、全网、全行业范围的**热门中文/英文词汇、短语、句子、名言**，整合成一份 Markdown 词汇日报。

**核心定位：跨行业词汇收纳。** 覆盖当天社交媒体热词、各行业专有名词、名人金句、网络流行语、实用短语搭配，中英双语并重。

**特别注意覆盖非互联网行业**：能源（油价、电池）、房地产（楼市政策、保障房）、医疗（新药审批、细胞疗法）、体育（世界杯、NBA）、金融（CPI、外汇）、汽车（新能源渗透率）、教育（高考、就业）、军事（国防、地缘政治）等。

## 输出文件

- 保存路径：`~/Documents/Daily news/知识收纳/多看YYYY-MM-DD.md`
- 文件名：`多看` + 当天日期（如 `多看2026-09-17.md`）
- 保存目录不存在时先创建（`mkdir -p`）
- 报告顶部填写当天实际执行时间

## 执行流程

### Step 1: 确认日期

- 用 `date +%Y-%m-%d` 获取当天日期，不要自己推算
- 每个搜索词都要带上具体日期，否则会搜到往年结果

### Step 2: 搜索素材

用 WebSearch 分板块搜索，可配合 WebFetch 抓取百度热搜、今日热榜、Twitter/X 趋势等实时数据源：

- 当天社交媒体热门关键词（微博热搜、Twitter trending、Reddit 热门等）
- 各行业当天新出现的专用名词、特殊名词、专有名词（新产品名、新政策名、新概念等）
- 当天被引用的知名人物名言、金句
- 新兴词汇、网络流行语、行业黑话
- 中英文实用短语与固定搭配

### Step 3: 整合生成报告

按下面的结构生成 Markdown。**每个板块必须满 10 条，一条都不能少。**

| 板块 | 数量 | 说明 |
|------|------|------|
| 🔥 今日热词 | **10 个** | 当天核心热搜/热词 |
| 💬 今日金句/名言 | **10 条** | 当天被引用的名言金句 |
| 📌 行业专有名词 | **10 个** | 各行业的专业术语/概念 |
| 🌐 网络流行语/新兴词汇 | **10 个** | 当天走红的新词/梗 |
| 📖 实用短语/搭配 | **10 个** | 中英文实用表达 |

**行业覆盖**：必须覆盖**至少 8 个不同行业**（AI/科技、体育、能源、汽车、房地产、医疗、金融、娱乐、教育、军事、国际政治、法律、社会民生等）。

**语言比例**：中文与英文内容大致 6:4。

**每条词条格式**：

```markdown
### 1. [词汇/短语]
- **语言：** 中文 / 英文
- **来源/出处：**
- **领域：** [标注所属行业]
- **解析：** 详细解释，包括背景、含义、使用语境
- **翻译：** 中英文互译
- **场景用途：**
- **例句：**
  - 中文：
  - English：
```

### Step 4: 保存

写入输出路径后结束任务，向用户简要汇报今日收录条数与最值得一看的 3 条即可，**不要把全文粘贴到对话里**。

## 注意事项

- **只用真实搜索结果，禁止编造词条、来源或释义**，搜不到就写「今日未获取到明确结果」
- 报告全文使用简体中文；英文词条保留原名并附中文释义
- 释义要写清背景与使用语境，不要只给一句生硬的同义替换
- 涉及境外地区或政治人物时，按中国官方表述规范书写（中国台湾/中国香港/中国澳门）
- 不收录违规、低俗、涉政内容，遇到直接跳过
