# 每日热门 · 搜索指南

所有搜索词都要拼上具体日期（`YYYY年M月D日`），避免搜到往年同日内容。
推荐用法：`WebSearch` 搜列表，`WebFetch` 抓榜页正文。

| 平台 | 搜索词模板 | 备注 |
|---|---|---|
| 微博 | `微博热搜榜 YYYY年M月D日` / `微博 热搜 第一 YYYY年M月D日` | 找当日热搜榜完整列表或 TOP 条目 |
| 抖音 | `抖音热榜 YYYY年M月D日` / `抖音 热点 排行 今日` | 关注高赞视频、挑战赛、话题播放量 |
| 快手 | `快手热榜 今日 YYYY年M月D日` / `快手 热门视频 排行` | 快手偏下沉市场，留意老铁文化、直播带货 |
| 小红书 | `小红书 热搜 今日 YYYY年M月D日` / `小红书 热门笔记 话题` | 偏生活方式：穿搭、美妆、旅行、探店、情感 |
| B站 | `B站 热门榜 今日` / `哔哩哔哩 热榜 YYYY年M月D日` | 关注 UP 主、鬼畜、科技区爆款 |
| 知乎 | `知乎热榜 今日 YYYY年M月D日` | 关注高讨论度社会话题 |

**抓取技巧**：
- **`tophub.today` 的分平台子页是当日榜的最佳入口（2026-09-21 实测成功）**，首页只有导航链接、拿不到条目，必须直接 `WebFetch` 子页：
  - 微博热搜榜 `tophub.today/n/KqndgxeLl9` → 返回**当日 08:20 / 10:20 等时点的上榜快照**，格式为「时刻 + 话题 + 热度值（万）」，可直接抄榜位与热度
  - 抖音总榜 `tophub.today/n/DqQvNABoNE` → 返回 TOP20 及**每条的具体播放量**（如 8044 万），是拿抖音量化数据最省事的路径。**注意：该子页可用性会波动（2026-09-22 返回 404），失效时改用「当日媒体报道 + 平台公开数据」反推**（如抖音热点累计曝光量、团购 GMV、话题观看量等，可在今日头条/微博的电商与消费类稿件中找到）
  - B站全站日榜 `tophub.today/n/74KvxwokxM` → 返回全站日榜与播放量
  - 知乎热榜 `tophub.today/n/mproPpoq6O`、百度实时热点 `tophub.today/n/Jb0vmloB1G`、今日头条热榜 `tophub.today/n/x9ozB4KoXb` 同理
  - **无快手子页**（快手榜仍需另找，实测连续多日失败）
- 榜单类站点（如 tophub、今日热榜类聚合页）可直接 `WebFetch`，一次拿到多平台榜位
- **微博榜单页拿不到完整榜时**：用 Apple Podcast《热搜吃瓜专家》（`podcasts.apple.com/cn/podcast/.../id1778404163`）反查——该节目逐小时更新微博热搜条目与量级，`WebSearch` 搜「平台名 + 具体事件关键词」即可命中其文字摘要
- **猫眼 `piaofang.maoyan.com/dashboard`** 单页同时给「实时票房榜（含上映天数/累计票房/排片场次）」与「实时收视率榜（含市占率）」，是拿票房 + 收视双指标最快的入口
- 单个平台搜不到当日榜时，改用「平台名 + 具体事件关键词」反查
- 记录榜位（第X位）或量级（播放量/点赞数），比只写「很火」有价值
- 注意区分**微博主榜与文娱榜**：新浪娱乐的 detail 稿常写「冲上文娱榜第 X 位」，这是独立榜位，可放心引用

**去世 / 重病类消息的核实路径**（2026-09-22 固化）：**AP News + 当地主流报纸（如洛杉矶时报）+ 家属发言人**三方交叉确认后方可写入报告；微博话题只能作为「热度佐证」，不得作为事实来源。`starsalert.com` / `tmz.tv` 仅作线索入口。

## 六、信源可靠性分级（实测结论，务必遵守）

按以下优先级取数，**不同等级的数据不可混用**：

| 等级 | 信源形态 | 可取数据 |
|---|---|---|
| ✅ 高 | 平台热榜聚合类公众号/简报文章（如「昨夜今晨二十条」「每天三分钟读懂全网热点」体例），一次给出微博/抖音/百度/知乎/头条的榜位与热度值 | 榜位、热度值、播放量 |
| ✅ 高 | 官方公告、法院/警方通报、人民网/新华社/新浪娱乐/搜狐娱乐等主流媒体 | 事件事实、票房、收视率、涨粉数 |
| ✅ 高 | 榜单站（千瓜数据、viralmint、tubestats、yt50）、Billboard / Netflix 官方榜单页 | 涨粉量、播放量、榜位 |
| ❌ 低 | 搜狐/网易「穿搭指南」「营销分析」类 SEO 稿，常自造「小红书热搜 TOP3」「话题阅读破 X 亿」「播放破 X 亿」等无法核实的数字 | **一律不得引用其数字**，只能抽象成「换季穿搭是当季种草主题」这类定性表述 |
| ❌ 低 | **搜狐号 `sohu.com/a/<id>_122066679` 这一账号下的稿子**（2026-09 实跑识别）：标题夸张（「引爆全网」「刷屏热搜」），正文塞入大量无法核实的精密数字与「AI 技术名词」 | **整篇不可引用**。实测它曾产出《心!(写的真好)》《万事顺自然》(自称「微博热榜连续 17 天 TOP5」「小红书 890 万篇笔记」)、《贵州小黄侗寨晒秋》(自称「话题 8.2 亿次」)、《淄博十中宿舍整顿月》等疑似 AI 批量生成的伪热点 |

**识别伪热点的两条硬规则**（2026-09-21 补充）：

1. **时间自洽性检查**：若稿件描写的是「当晚 19:30 起」「20:00 整」的事件，而检索时刻在该日中午之前，则该稿件必然为伪造或日期错乱，直接弃用。实测案例：一篇自称「9月21日晚在淮南完成秋晚核心录制」的稿子，在 11:30 就被检索到。
2. **同一账号交叉验证**：同一搜狐/网易账号名下同时存在多篇风格一致、数字华丽但无出处的「伪热点」，则该账号全部内容弃用；改从新浪娱乐、腾讯新闻、官媒（如安徽青年报、地方政府网）核对同一事件。实测：央视秋晚的真实信息（9月25日 20:00 播出、淮南人民公园湖区录制、央视boys 四年后合体、筷子兄弟首唱 AI 原创歌）可从新浪娱乐 9/20 稿 + 腾讯新闻 9/21 稿 + 安徽青年报交叉获得。

其他实测要点：

- **微博/抖音/百度/知乎当日榜**：用「平台名 + 热搜榜 + 具体日期」搜聚合类文章最快；搜不到当日榜时用「平台名 + 具体事件关键词」反查。
- **快手**：当日热榜条目经常检索不到（连续多日如此，截至 2026-09-22 已五连败：09-18/19/20/21/22）。此时不要编造，写「今日未获取到明确结果」，可另附当日发布的快手内容盘点（注明是盘点而非当日榜，如平台创作者大会数据、走红博主采访）。
- **微博热搜**：`tophub.today/n/KqndgxeLl9` 可拿到当日多时点的上榜快照（含热度值），是当前最稳的微博取数路径（2026-09-22 实测一次拿到 08:20 与 10:20 两个时点）；注意**主榜与文娱榜是独立榜位**，新浪娱乐 detail 稿常写「冲上文娱榜第 X 位」，可放心引用。榜首位若为涉黄/涉政/金融类，按要求跳过不收录。
- **电影票房**：用「微博『每日票房粗报』（含当日单部影片票房 + 全国场次/人次）+ 猫眼专业版」组合最快，比单抓 `piaofang.maoyan.com/dashboard` 更省一轮请求，且粗报直接给出分片票房。
- **小红书**：拿不到官方热搜时，有两条替代路径——① 千瓜数据日榜（更新时间为当日 08:00）取「达人涨粉 TOP」；② 若检索到**什么值得买（smzdm）等平台的数据型长文**（作者逐条统计社媒帖子数/评论数并公开口径，如「122 篇帖中 60% 是引流帖」「719 条评论 85% 在留码数」），可引用，但须标注为**第三方统计**而非平台官方数据。
- **B站**：官方热榜不好抓，改用「当日爆款内容盘点」文章反推（如 UP 主单集播放量对比平台官方赛事账号播放量，倒挂数据很有说服力）；亦可直接 `WebFetch` RSSHub 镜像 `rsshub.rssforever.com/bilibili/weekly` 拿「每周必看」当周榜。
- **X / YouTube / TikTok**：trends24、rattibha（X 分地区趋势）、glyphsignal / viralmint（YouTube 分国家 trending）、whotag（TikTok 分品类周榜）均可直接 WebFetch。
- **去世/获刑/患病类消息**必须二次搜索核实（搜「姓名 + 去世/获刑」），确认日期与官方来源后再写入报告。
- **内容边界**：国家纪念日（如九一八）、金融行情、房地产、货币政策、AI 技术、企业融资、政策解读即使当日霸榜也**不收录**；未成年受害、涉黄涉毒细节只写必要事实，不做过程描写。

## 七、质量校验清单

生成报告前逐条自检：

- [ ] 国内条目 ≥ 6 条，国外条目 ≥ 5 条
- [ ] 每条都有具体来源平台 + 可量化的热度指标（榜位/播放/点赞）
- [ ] 所有日期都是**当年**，没有混入往年同日新闻
- [ ] 没有收录行业专业资讯（金融/半导体/AI技术/融资/政策解读）
- [ ] 未证实的传闻已标注「传闻/未证实」
- [ ] 无平台违规、低俗、涉政内容
