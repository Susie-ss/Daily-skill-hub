# Daily Hot Topics（每日热门）

## Overview

每天收集**大众向**的娱乐八卦与各平台热门内容，覆盖国内（微博、抖音、快手、小红书、B站、知乎）与国外（YouTube、TikTok、X、Instagram、欧美日韩娱乐圈）两大赛道，整合成一份结构化 Markdown 报告。

**核心定位：这是"吃瓜日报"，不是行业日报。** 只收录普通大众会刷到、会讨论的热点，包括明星娱乐八卦、影视综、网红主播、热门视频、社会民生话题、赛事娱乐化话题、流行梗/热梗、时尚消费趋势等。

**明确排除**（这类内容请勿收录）：金融行情、股票基金、行业研报、半导体/芯片、AI 技术前沿、企业融资并购、政策法规解读、B端产品动态等一切"行业专业资讯"。

## 输出文件

- 保存路径：`~/Documents/Daily news/每日热门/每日热门_YYYY-MM-DD.md`
- 文件名：`每日热门_` + 当天日期（如 `每日热门_2026-09-17.md`）
- 保存目录不存在时先创建（`mkdir -p`）
- 报告内「生成时间」填写当天实际执行时间

## 执行流程

### Step 1: 确认日期

- 用 `date +%Y-%m-%d` 获取当天日期，不要自己推算
- 覆盖范围：**前一天晚间 ~ 当天上午**的热点（11:30 执行，正好覆盖隔夜到上午的热度）
- 周一执行时需额外补搜周末两天的娱乐大瓜（周末是八卦高发期）

### Step 2: 搜索资讯

按 `references/search_guide.md` 里的平台清单和搜索词模板逐项搜索。要求：

- **国内**：娱乐八卦 + 微博热搜 + 抖音 + 快手 + 小红书 + B站/知乎，合并后 **至少 6 条**
- **国外**：YouTube / TikTok / X 趋势 + 欧美日韩娱乐圈，**至少 5 条**
- 每个搜索词都要带上具体日期（如「微博热搜 2026年9月17日」），否则会搜到往年结果
- 同一事件在多平台都出现时合并为一条，标注「多平台热议」，并写明各平台热度差异

### Step 3: 整合生成报告

按 `assets/report_template.md` 的模板生成 Markdown。核心要求：

- **🔥 今日最热 TOP 5**：全平台综合热度最高的 5 条，一句话讲清「发生了什么 + 为什么火」
- **分区呈现**：国内娱乐八卦 / 国内平台热榜 / 国外热点 / 流行梗与趋势
- 每条资讯格式：**标题 → 热度来源（平台 + 榜位/量级）→ 事件简述 → 讨论焦点**
- 尽量保留具体数字：热搜排名、播放量、点赞数、涨粉数、票房、收视率等
- 有争议性内容（塌房、翻车、撕逼）用中性客观表述，不做价值判断、不站队
- 涉及境外艺人或地区时，按中国官方表述规范书写（中国台湾/中国香港/中国澳门）

### Step 4: 保存并汇报

保存到输出路径，向用户简要汇报今日 TOP 3 热点和报告亮点，**不要把全文粘贴到对话里**。

## 注意事项

- **只用真实搜索结果，禁止编造热点、数据、榜位**。搜不到就写「今日未获取到明确结果」，不要脑补
- 报告全文使用简体中文；国外内容需翻译成中文，可保留原名
- 明星恋情、婚变、塌房等未经证实的传闻，必须标注「传闻/未证实」
- 若搜索结果时效性差（搜到往年同日内容），务必以最新年份为准，注意核对年份与日期
- 榜单类内容优先找当日榜（热搜榜/热榜/趋势榜），找不到当日榜就用当日新闻报道反推热度
- 避免平台敏感内容：不收录违规、低俗、涉政内容，遇到直接跳过
