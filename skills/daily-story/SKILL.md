# Daily Story Skill — 每日故事·知识日报

每日从全领域收集历史知识、文学知识、故事典故、地理文化等，覆盖互联网网站和 B 站、喜马拉雅、得到、知乎、小红书、抖音、YouTube 等音频/视频/图文综合平台，生成内容丰富的结构化 Markdown 知识日报。

---

## Overview

This skill:
1. 搜索多个来源（网页 + B站/喜马拉雅/得到/知乎/小红书/抖音/YouTube等平台），获取当日值得学习的历史、文学、地理、典故、诗词等知识
2. 去重并按主题分类整理
3. 将重点英文内容翻译为中文摘要
4. 写入 `<output_dir>/每日story_YYYY-MM-DD.md`
5. 更新 `<output_dir>/index.md` 索引

---

## Trigger Detection

激活此 skill 时，用户提到：
- 每日故事 / 每日知识 / 知识日报 / 文史日报
- 每日story / daily story / 历史知识 / 文学典故
- 每日诗词 / 每日地理 / 传统文化
- 定时收集故事 / 自动生成知识日报

## Execution Workflow

### Step 1 — Resolve Output Path

输出目录：`~/Documents/Daily news/story/`

如果用户指定了不同目录，使用用户指定的目录。
确保目录存在：

```bash
mkdir -p <output_dir>
```

### Step 2 — Determine Today's Date

```bash
date +%Y-%m-%d          # macOS / Linux
```

使用该值作为文件名：`<output_dir>/每日story_YYYY-MM-DD.md`

### Step 3 — Collect Knowledge

使用 `WebSearch` 进行多角度搜索。每个分类至少搜索 2-4 个不同的关键词组合，确保内容多样性和丰富度。

**搜索策略：** 每次搜索使用不同的关键词组合，覆盖不同子领域。对于每个搜索，获取排名靠前的 5-10 个结果并提取有效信息。

#### 搜索执行原则

1. **搜索广度优先**：每个分类至少执行 3-5 组搜索，确保覆盖不同子方向
2. **结果筛选**：优先选择信息密度高、权威性强、适合作为知识学习的内容
3. **多平台覆盖**：覆盖 B站、喜马拉雅、得到、知乎、小红书、抖音、YouTube、网易公开课、看理想等多个平台
4. **中英双语**：部分分类搜索英文关键词获取国际视角的内容，并翻译为中文
5. **每分类 10+ 条**：每个分类最终收录至少 10 条知识，总条数目标 100-150 条

#### 格式规则

- 文件名必须为 `每日story_YYYY-MM-DD.md`
- 顶部统计总知识条数
- **每个分类至少 10 条**，总条数目标 **100-150 条**，多多益善
- 每个条目包含：标题、来源链接、内容摘要
- B站视频条目单独一个板块展示
- 使用 emoji 作为分类标题
- 内容为主，不凑数——确保每条都有实质信息量

### Step 5 — Update Index

追加一行到 `<output_dir>/index.md`：

```markdown
- [📖 每日故事 YYYY-MM-DD](./每日story_YYYY-MM-DD.md) — {total_count} 条知识
```

如果 `index.md` 不存在，先创建带标题的文件：

```markdown
# 📚 每日故事·知识日报 索引

> 每日全领域知识汇集——文学、历史、地理、典故、诗词、传统文化，持续更新。

---
```

### Step 6 — Confirm to User

- 总知识条数

## Automation Setup (Scheduled Daily Run)

要设置每天自动运行，创建自动化：

```
Name: 每日知识故事
Schedule: RRULE:FREQ=DAILY;BYHOUR=14;BYMINUTE=0  (每天 14:00 运行)
Prompt: 请使用 daily-story skill，收集今日的全领域历史知识、文学知识、故事典故、地理文化等，生成每日story文件到 ~/Documents/Daily news/story/ 目录
Skill: daily-story
```

自动化 prompt 必须自包含——不需要追问。

## Notes

- 中英文内容兼顾，英文内容需提供中文翻译/摘要
- 每个条目控制在 100-300 字摘要，精炼有料
- 优先选择信息准确、来源可靠的内容
- 对于视频/音频平台内容，优先推荐高播放量、高评分、内容优质的作品
- **每分类至少 10 条**，总条数目标 **100-150 条**，保持内容丰富度
- 如果某分类今日搜索不到足够优质内容，可适当减少该分类条数，从其他分类补充
